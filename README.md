# ✊ Rock Paper Scissors Game

A beginner-friendly Python Rock-Paper-Scissors game featuring three rounds, score tracking, input validation, and random computer choices.


## 🎮 About the Project

This project is a command-line Rock-Paper-Scissors game where you compete against the computer in three rounds.

The game randomly generates the computer's choice and compares it with the player's selection to determine the winner of each round.

At the end of the game, the final scores are displayed and the overall winner is announced.

The game is internally named **Triple Showdown**.

## ✨ Features

- Three-round gameplay
- Random computer choices
- Input validation
- Score tracking
- Automatic winner detection
- Replay option
- Exit option

## 🛠️ Technologies & Concepts

- Python
- Random Module
- While Loops
- For Loops
- Conditional Statements
- User Input Handling


## 🎯 Project Purpose

This project was created to practice fundamental Python programming concepts, including loops, conditional logic, input validation, random selection, and basic game development.
